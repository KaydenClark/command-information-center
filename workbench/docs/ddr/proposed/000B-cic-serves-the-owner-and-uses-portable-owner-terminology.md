# DDR-000B — CIC serves the Owner and uses portable Owner terminology

## Decision

> Agreed—use Owner throughout. That keeps the definition suitable for anyone setting up their own CIC.

## Why

The Owner asked: “What if anyone else downloads and sets up their CIC? Use Owner.”

## Considered and Rejected

Naming the original Owner in the reusable product definition was rejected because another person can download and set up their own CIC.

## Consequences

Destination wording uses Owner rather than a personal name. This makes no decision about runtime account or authentication architecture.
